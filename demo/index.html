Capability boundary demo

An opaque-origin iframe can only ask the host for explicitly brokered demo capabilities.

Prototype, not a production security product. The widget is a local example, network responses are simulated, and no host cookies are read. A sandboxed iframe does not provide drop-in compatibility or containment for arbitrary existing scripts.
